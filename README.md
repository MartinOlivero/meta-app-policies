## Keeping these honest

These documents state what the applications actually do. If either application starts
processing new data, adding a sub-processor, or using a new AI provider, **update the
policy in the same change** — a policy that describes something the app no longer does
is a compliance problem during App Review, not a formality.

Sections most likely to go stale:

- Sub-processor tables (§6 in AutomLead, §5 in Tincho_I_G)
- Retention periods (§7 / §6)
- The AI section in AutomLead (§5) — model provider and what it decides
